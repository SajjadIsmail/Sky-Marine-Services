## Quick Download Instructions

### Option 1: Manual Download

1. Visit the free image websites listed above
2. Search for the recommended terms
3. Download high-resolution images (minimum 1920x1080 for carousel, 800x600 for services)
4. Rename them according to the list above
5. Place them in the appropriate folders

### Option 2: Using PowerShell Script

Run the download script (see download-images.ps1) to fetch sample images from Unsplash API.

### Option 3: Use Placeholder Images Temporarily

The app will use placeholder images from https://placehold.co if local images are not found.

## Image Optimization Tips

- **Format**: Use JPG for photos, PNG for logos with transparency
- **Size**: Compress images to reduce load time (use tools like TinyPNG)
- **Dimensions**: 
  - Carousel: 1920x1080px
  - Services: 800x600px
  - Logos: Actual size needed (don't upscale)
- **File Size**: Aim for <500KB per image after compression

## Attributions

If using free stock photos, check if attribution is required:
- Unsplash: No attribution required but appreciated
- Pexels: No attribution required
- Pixabay: No attribution required

## Custom Company Images

For company-specific images (logo, certificates, etc.):
- Request official logos from your company's brand/marketing department
- Ensure you have rights to use all images
- Use high-resolution versions of company assets
